## 🚙 About the Project

This project is a **6-wheel suspension rover being designed in SolidWorks**.

The main focus is on building the rover as a complete mechanical system, including the chassis, wheel assemblies, suspension structure, motor mounts, and other supporting components.

Instead of simply modelling a single part, this project is helping me understand how multiple mechanical components come together to form a working rover platform.

---

## 🎯 Project Objectives

* Design the rover chassis in SolidWorks
* Model the suspension mechanism
* Design the wheel and motor assemblies
* Create proper mechanical connections between components
* Build the complete rover assembly
* Practice designing parts with real-world dimensions
* Improve assembly and mechanical design skills

---

## ⚙️ Main Components

The rover design consists of:

* Main chassis / top platform
* Suspension arms
* Wheel assemblies
* Motor mounts
* Drive motors
* Axles and mounting hardware
* Structural brackets
* Fasteners

The individual components are being modelled and assembled in SolidWorks.

---

## 🔩 Mechanical Design

One of the main parts of this project is understanding how the **suspension and wheel arrangement** work together.

The suspension structure allows the wheels to remain connected to the chassis while providing movement between the wheel assemblies and the main platform.

The design also requires careful attention to:

* Part alignment
* Clearances
* Mates
* Symmetry
* Wheel positioning
* Motor placement
* Structural support
